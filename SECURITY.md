# Security Policy

## Supported versions

Security fixes are applied to the latest released version of PagedMoE on the
default branch. Pre-release / untagged clones should update to the newest
commit when a fix lands.

## Reporting a vulnerability

Please **do not** open a public GitHub issue with exploit detail.

Email: **noah@qwertycode.org**

Include:

- A short description of the issue and impact
- Steps to reproduce (or a proof of concept)
- Affected version / commit if known

You should receive an acknowledgement within a few days. Please give a
reasonable window for a fix before any public disclosure.
